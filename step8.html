2. Naissance du Web — Tim Berners-Lee et premières implémentations

1989-1991 — Tim Berners-Lee au CERN : HTML, HTTP, URL

Tim Berners-Lee propose, au CERN, un systeme pour partaber des documents entre chercheurs en utilisant l'hypertexte et Internet

  • HTML (HyperText Markup Language) : format pour structurer les documents et liens.
  • HTTP (HyperText Transfer Protocol) : protocole d'echange client/serveur.
  • URI/URL : mecanisme d'adressage des resources sur le reseau/li>

Exemple de code HTML : <p> Hello world </p>

1993-1994 — Premiers navigateurs graphiques : Mosaic et Netscape

Le navigateur Mosaic (1993) popularise l'affichage graphique d'images et de textes meles ; il rend l'experience web utilisable par

Consequences :

l'accessibilite et la convivialite des navigateurs declenchent une croissance exponentielle

1994-1996 — Standardisation et premiers moteurs de recherche

A mesure que le Web se repand, la necessite de standards devient imperative. le W3C es fonde(1994) par Berners-Lee

Les premieres problematiques emergent :indexation , performance. securite, et modelisation des donnees sur le Web.

3. Le Web sémantique, Linked Data et Sold

Le Web semantique : objectifs et composants

Le web semantique vise a ajouter une couche de metadonnees et de signification aux contenus web afin que les machines puissent

  • RDF (Resource Description Framework) : modele de triplets pour representer le donnees.
  • OWL : coolongies pour definir des vocabulaires et relations complexes.
  • SPARQL : langage de requete pour interoger des graphes RDF.
  • Microformats et JSON-LD : moyens d'encoder des metadonnees dans les pages web.

Linked Data

Tim Berners-Lee a propose des principes pour publier des donnees liees (Linked Data) : utiliser des URIs.

Solid (Social Linked Data)

Tim Berners Lee:

"The Web as i emaginated, we have not seen it yet."

Solid est une inactive de Tim Berners-Lee visant a redonner le controle des donnees personnelles aux utilisateurs

Avantages : autonomie des utilisateurs, separation des donnees et des services, imperabilite de donnees via RDF/JSON-LD.

Ruben Verborgh:

Three paradigm shifts we need to prepare for:

  • End users become data controllers.
  • Apps become views.
  • Interfaces become queries.

Cas d'usage du Web sémantique

Exemples : moteurs de recherche, assistants vocaux, integration de donnees scientfiques, catalogues de bibloghraique
